# Self-Balancing Motorcycle

A self-balancing motorcycle built as a robotics and control systems project.

The goal was to create a two-wheeled motorcycle that could detect its own tilt and automatically correct its balance using sensors, a motor, and a feedback control system.

## What I worked with

- Arduino / embedded C++
- IMU sensor
- DC motors
- Motor controllers
- Feedback control / PID
- Electronics and wiring
- Mechanical assembly

## How it works

The IMU measures the motorcycle's orientation. The Arduino processes the sensor data and calculates how the balancing motor should respond. The motor then applies a corrective force to keep the motorcycle upright.

This creates a continuous feedback loop:

**Sensor → Controller → Motor → Correction → Sensor**

## What I learned

Through this project I gained practical experience with embedded systems, sensors, motor control, feedback systems, debugging hardware, and integrating software with physical components.
